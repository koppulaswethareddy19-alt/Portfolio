# K. Swetha Portfolio

A responsive personal portfolio website built from scratch with HTML, CSS and JavaScript, using the supplied Figma portfolio template as visual inspiration.

## Run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server, or double-click it in your browser.
3. Edit the content in `index.html` and styling in `style.css`.

## Personal details used
Content is based on the supplied resume/profile files. Replace the phone number, email, LinkedIn and project links if needed before publishing publicly.

## Before GitHub Pages
- Add real project/demo/GitHub links to each project.
- Add a professional profile photo if you want one.
